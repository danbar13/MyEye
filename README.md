# MyEye (אפליקציית למידה אנטומית וקלינית על מבנה העין ומחלת הרשתית)

אפליקציית ווב אינטראקטיבית ומתקדמת ללמידה והמחשה קלינית של מבנה העין האנושית, אנטומיה פיזיולוגית, ופתולוגיות רשתית (חסימת וריד רשתית סעיפי – BRVO, בצקת מקולרית ציסטואידית – CME, וקטרקט).

---

## 🌟 תכונות עיקריות (Key Features)

1. **איור אנטומי אינטראקטיבי (כרטיסייה 1):**
   - איור רפואי אותנטי ברזולוציה גבוהה התומך במצב בהיר ובמצב כהה.
   - נקודות עניין אינטראקטיביות (Hotspots) פועמות לפתיחת הסבר קליני מפורט.
   - בקרות זום (+, -, 100%, איפוס) ותמיכה מלאה בגלילת עכבר וגרירה (Pan).

2. **הדמיית תלת-ממד בחתך אנטומי (Cutaway 3D):**
   - מודל תלת-ממדי מותאם של גלגל העין בחתך 90 מעלות (מבט פרופיל אנטומי).
   - הדמיית פרישת שכבות לאורך הציר האופטי (**"פרק עין לשכבות" / Exploded View**).
   - בקרות זום וסיבוב מלאות בסרגל צף ובגלגלת העכבר בכל הכרטיסיות.

3. **הדמיית בצקת מקולרית ו-BRVO (כרטיסייה 2):**
   - מבט ממוקד ישירות אל חלל העין הפנימי (Concave Interior) לכיוון הרשתית והמקולה.
   - סרגל גרירה רציף למדד עובי מקולרי מרכזי (CST) מ-240µm (תקין) ועד 565µm (בצקת חמורה).
   - הדמיית כיסי נוזל ציסטואידיים זוהרים (Fluid Cysts) ומוקדי דלף וסקולריים.
   - תוויות אנטומיות חכמות עם קווי הצבעה עדינים שאינם מסתירים את המבנה.

4. **הדמיות טיפולים קליניים (כרטיסייה 3):**
   - **הזרקה תוך-עינית (Intravitreal Injection):** כניסת מחט דרך ה-Pars Plana בלובן העין, שחרור טיפת תרופה זוהרת לחלל הזגוגית, ונסיגת הבצקת.
   - **צריבה בלייזר ארגון (Argon Laser 532nm):** מעבר קרן לייזר ירוקה דרך האישון וחשיפת מוקדי צריבה מדויקים ברשתית.
   - הרכבה אוטומטית של העין בעת הפעלת הטיפולים לדיוק אנטומי של 100%.

5. **הדמיית קטרקט והחלפת עדשה (IOL - כרטיסייה 4):**
   - המחשת שלבי עכירות העדשה הטבעית והחלפתה בעדשה מלאכותית צלולה.

6. **תרשים מעקב כרונולוגי של עובי הרשתית (OCT Chart Modal):**
   - תרשים מעקב מלא (2021–2026) הכולל ציוני דרך של הזרקות Eylea, Lucentis, Ozurdex וטיפולי לייזר.

7. **ממשק משתמש מתקדם:**
   - תמיכה מלאה בעברית (RTL).
   - תצוגה מפוצלת (Split-Pane) הניתנת לשינוי גודל בגרירה (25%–75%).
   - התאמה רספונסיבית מלאה למובייל, טאבלט ומסכי מחשב.
   - מצב כהה (Dark Mode) ומצב בהיר (Light Mode).

## 🛠️ טכנולוגיות (Tech Stack)

- **React 18**
- **Three.js** & **@react-three/fiber** & **@react-three/drei**
- **Vite**
- **Tailwind CSS**
- **Lucide React** (Icons)

## 🚀 התקנה והרצה מקומית (Local Development)

```bash
# שכפול המאגר
git clone <repository-url>
cd MyEye

# התקנת תלויות
npm install

# הרצת שרת פיתוח
npm run dev

# בנייה לפרודקשן
npm run build
```
